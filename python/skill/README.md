# Python Learning & Practice Repository 🐍

একটি comprehensive Python শেখার repository যেখানে **Fundamentals থেকে Advanced** সব কিছু আছে।

## 📚 Learning Path (Recommended Order)

### Phase 1: Python Fundamentals
- **01_Basics** - Loops, conditionals
- **02_Functions** - Built-in, lambda, args/kwargs
- **03_File_Handling** - Reading, writing, file operations
- **04_Error_Handling** - Exceptions, try-except

### Phase 2: Intermediate Concepts
- **05_OOP** - Classes, inheritance, polymorphism
- **06_Data_Structures** - Lists, dicts, sets, tuples
- **07_JSON_Data** - Parsing, handling JSON

### Phase 3: Advanced Python
- **08_Decorators** - Function & class decorators
- **09_Generators_Iterators** - Generator functions, custom iterators
- **10_Context_Managers** - With statements, resource management
- **11_Async_Await** - Asynchronous programming
- **12_Multi_Threading** - Threading concepts

### Phase 4: Data Science (Optional)
- **13_Data_Analysis** - NumPy, Pandas basics

### Phase 5: Problem Solving (Optional)
- **DSA** - Data structures & algorithms
- **LeetCode** - Competitive coding problems
